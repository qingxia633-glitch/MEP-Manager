# 开发路线：让普通水电安装从业者能独立完成算量

## 第一版 v0.1：先形成能用的闭环

已实现项目建立、图纸图片标定、折线测量、设备点数、可追溯明细、材料汇总、实际收支和完整备份。

第一轮试用重点观察：

1. 用户能否在不阅读长说明的情况下完成第一笔管线测量？
2. 是否容易理解“基础数量、重复份数、补充数量、备料损耗”的区别？
3. 测量点是否容易点准，放大、撤回和查找原记录是否顺手？
4. 实际图纸尺寸、单价、规格和楼层组织方式是否适合现场习惯？

## 下一轮：拿真实图纸改善易用性

- 用用户提供的实际给排水 / 电气图纸验证比例、长图与大图性能。
- 添加可拖动测量点、图纸平移、明确的每段长度和正交辅助。
- 保存标定参考线，支持第二段尺寸复核与标定偏差提示。
- 增加楼栋 / 楼层 / 系统的逐级组织和常用规格记忆。
- 为重复楼层、电线根数、竖向长度提供解释清楚的专用填写步骤。
- 以现场习惯定义可打印、可交付的工程量表和材料单。

## 图纸能力扩展

- 优先增加 PDF 多页选择与渲染，明确页码、标定信息和测量记录的关联。
- 随后研究 DXF 图层、线段与文字读取，用原始图形坐标替代截图像素测量。
- DWG 支持需要选定合法可用的解析 / 转换方案，再评估安装成本、离线能力与文件兼容性。
- 自动识别采用“给出候选 → 用户确认 → 保存证据”的流程，避免把识别猜测直接计入正式工程量。

## 现场管理扩展

- 工人、工日、计件、借支与工资结算。
- 材料采购、入库、领用与库存差异。
- 合同金额、进度款、应收应付，与现有实际收支关联。
- 在本地版本验证稳定后，再讨论桌面安装包、移动端体验和云端同步。

## v0.3 现场材料与人员台账（按现场闭环实现）

### 材料

- 建立统一材料名称、规格、专业、单位和安全库存；图纸归类只能选择材料库项目，避免同物多名。
- 按材料记录计划量、进场量、退场量、领用量、盘点量和进场日期；自动计算可用结余、理论结余和差异。
- 工程量清单确认后生成计划用量，现场领用只影响库存，不改写图纸原始测量；结余不足时提示预警。
- 每笔进场、领用、退场保留经手人、位置、备注，可回溯到项目和楼层。

### 人员与工资

- 项目内建立工人花名册：姓名、工种、联系电话、身份证号、身份证地址、银行卡、卡号和备注；敏感字段只在本机备份中保存并支持隐藏显示。
- 按日期和班组记录出勤时段、工日、计件、单价、借支和应付工资；工资结算生成一笔可追溯的项目支出。
- 工资明细和材料明细分开统计，同时在项目收支中保留来源链接，避免重复记账。

### 验收规则

- 同一材料跨图纸、跨楼层汇总，明细仍显示来源；不同规格不得合并。
- 库存数量变化可由每一笔业务重算，修改或删除业务不会留下“看不见”的差额。
- 工资和材料导出前显示脱敏预览；备份恢复后校验项目、人员、台账和工程量之间的关联。

这些是待验证方向，不代表已经具备的功能；下一轮优先级应根据用户试用第一版后的反馈决定。
