# v0.3 当前状态

本机版新增可靠直线捕捉、选线段归类、同名重叠拦截、确认补线、自绘支路、竖向明细、附属材料、库存、花名册和出勤工资。最大缩放3200%。新备份使用密码加密；旧备份仍可恢复为副本。

## 使用

运行 `npm start`，打开 http://127.0.0.1:4173/ 。DWG需要配置本机 `MEP_ODA_PATH`；单文件HTML只直接读取图片/ASCII DXF。服务入口和文件入口的浏览器存储彼此独立。

已有项目保留；旧CAD选区缺少可靠几何数据，需要重新导入原CAD后使用新版捕捉。新版本并不把旧临时采样点当成可靠端点。

图纸测量支持手动选择类别；选线段只接受完整可见直线，复杂曲线与裁剪边缘请核对原图。两条断线可确认最近端点之间的补线长度；这不代表自动还原设计意图。增加支路不计支路之间的连接。

材料计划按专业、名称、规格、单位归并；计划与实际使用分开。付款而非应发工资进入实际收支。身份证/银行卡在普通列表中隐藏，仅在花名册窗口编辑；数据保存在当前浏览器，密码备份无法在忘记密码后找回。

竖向明细格式：说明,起点高度米,终点高度米,点数,每点根数。附材格式：名称,规格,总数量,单位。附材数量独立确认，不跟随主材重复份数放大。

## 验证

38项单元检查、19项浏览器检查通过；另用真实DWG在本机验证导入、捕捉、标定、测量、归类、重叠拦截、竖向、库存、工资及加密备份恢复。用于计算检查的标定值不是对该施工图真实尺寸的确认。真实工程资料不随仓库发布。
