# MEP-Manager · 水电小助手

面向普通水电安装从业者的工程算量与项目管理工具。第一版把操作做成“放图纸 → 定比例 → 点管线 / 点设备 → 看清单”，每笔数量保留来源和计算过程。

**当前版本：v0.2.0，CAD 试读体验版。** 不需要账号，不依赖在线图纸服务或外部字体。

## 新增：从 CAD 开始试用

“添加图纸”现在可选择 DWG 或 ASCII DXF。打开后按图中标题定位、滚轮放大、拖动平移，也可以按图层名称筛选。点击“使用当前区域”，生成测量底图，再用实际标注尺寸定比例。

DXF 在浏览器内读取，无需转换服务。DWG 需要本机安装 **ODA File Converter**，并在启动服务前通过环境变量 `MEP_ODA_PATH` 指向该工具的可执行文件。转换器不随项目分发，也不会自动安装。

Windows PowerShell 示例（将路径换成实际安装位置）：

```powershell
$env:MEP_ODA_PATH = 'C:\\path-to-converter\\ODAFileConverter.exe'
node server.cjs
```

直接打开离线 HTML 时可读取 ASCII DXF；DWG 需要使用上述本机服务。DWG 内容只发送到本机服务进行转换，不发送至公网；临时转换文件在完成或失败后清理。单份 DWG 限 30 MB，转换后的 DXF 限 100 MB，转换限时 90 秒。

**这是有限的二维 CAD 预览，不是完整 CAD 引擎。** 支持常见线段、多段线、圆弧、圆、椭圆、文字、块插入和普通二维裁剪块；不支持的代理对象、样条、遮挡、填充、表格、嵌入对象等会明确提示。仅显示模型空间，字体和部分对象可能失真或缺失。曲线用于预览，不能据此声称原生精确 CAD 算量。

CAD 坐标单位即使已设置，也不会自动当成准确测量比例；必须按图上尺寸标定。所有选区都会保留来源文件名和试读标记。不同楼层、系统图、平面图应分别选择，系统示意图不能按线长直接算量。

转换方式参考 [ODA 官方说明](https://www.opendesign.com/cn/guestfiles/oda_file_converter)；二维裁剪边界格式参考 [Autodesk DXF 文档](https://help.autodesk.com/cloudhelp/2021/CHS/AutoCAD-DXF/files/GUID-34F179D8-2030-47E4-8D49-F87B6538A05A.htm)。

## 立即试用

下载本项目并解压，使用 Edge 或 Chrome 打开 `index.html`。点击 **先试一份示例**，可以练习图纸测量；点击 **创建第一个项目**，建立自己的空项目。

也可以在安装 Node.js 18 或以上版本的电脑运行：

```sh
node server.cjs
```

打开 `http://127.0.0.1:4173`。无需安装运行依赖。服务只监听本机。

运行 `node build.cjs` 可生成 `dist/水电小助手.html` 单文件离线版，双击即可试用，适合发给不熟悉代码的同事。

**数据保存在当前浏览器、当前访问地址下。** 直接打开文件与通过本地服务打开使用不同的数据空间。换浏览器、换访问地址、移动文件或清理浏览器前，请先点击“备份数据”，然后在新入口“恢复备份”。恢复采用加入副本的方式，不覆盖已有项目。

## 第一版已经能做什么

| 功能 | 用法 |
| --- | --- |
| 项目管理 | 新建、切换、修改名称 / 位置、确认后删除项目 |
| 图纸管理 | 加入 PNG / JPG / WebP，单张不超过 15 MB；可使用 CAD 或 PDF 截图 |
| 图纸标定 | 选两个已知尺寸端点，输入实际米数；3600 mm 填 3.6 |
| 管线长度 | 沿起点、转弯、终点逐个点击，按标定比例计算折线长度 |
| 设备点数 | 逐个点选设备，可撤回；不需要先标定 |
| 工程量记录 | 手动录入、图纸测量、编辑、确认删除、按来源回图纸 |
| 数量计算 | 基础数量、重复份数、立管 / 预留等补充数量、备料损耗分开记录 |
| 材料清单 | 按专业、名称、规格、单位汇总；支持搜索、专业筛选与 CSV 导出 |
| 成本估算 | 用户自行填写单价，按备料量估算材料金额 |
| 项目收支 | 实际收入 / 支出录入、编辑、删除、结余统计及 CSV 导出 |
| 保存与恢复 | IndexedDB 本地保存、包含图纸及测量点的 JSON 完整备份、恢复副本 |
| 新手帮助 | 示例住宅项目、工具提示、常用材料快捷填写、三步使用指南 |

CSV 可以用 Excel 打开。它是表格交换文件，不是带样式的 `.xlsx` 工作簿。导出内容遵循当前筛选及“逐笔明细 / 材料汇总”视图。

## 算量规则

```text
基础长度 = 各段图纸像素距离之和 × 标定得到的米 / 像素
实际工程量 = 基础数量 × 重复份数 + 补充数量
备料量 = 实际工程量 × (1 + 自填损耗率 / 100)
材料估算金额 = 备料量 × 自填单价（每笔金额取到分）
```

- 损耗率默认 0，只影响备料量；不增加实际工程量。
- 重复份数为正整数，可以表达相同楼层或相同回路。电线根数需要人工核对，软件不会自动从线管推算电线根数。
- 立管、上下翻弯和接线预留应人工填写“补充数量”。平面截图不能自动提供这些长度。
- 重新标定只用于后续新测量。旧记录保留测量时的比例和点位，可追溯原计算。
- 汇总时按专业、名称、规格、单位区分；不同单价按逐笔金额相加。
- 显示最多 3 位小数，汇总保留原始数量。离散设备采购是否取整、包装数量如何处理，需要用户另行核对。
- 单价留 0 表示暂未估价；未填单价的记录不会计入金额。估算不含未单列的人工、运费、税费等。
- 实际收支与材料估算独立，收支结余不等于利润。

## 精度与当前边界

本版是**人工辅助算量工具**。v0.2 增加有限的 DWG 本机转换与 ASCII DXF 试读，尚未实现完整 CAD 还原、PDF 读取、自动识图、图层捕捉算量、定额计价、工资结算、材料库存或云端多人协作。

图纸图片要保持原长宽比例。倾斜拍照、截图拉伸或同图不同缩放比例的详图会影响长度准确性；应校正图片，或分别截图、分别标定。建议用较长的已知尺寸标定，放大后点选，再用另一段尺寸复核。算量结果需要结合施工图和现场核对。

每个项目最多 100 张图纸，总项目数不超过 200；单图尺寸不超过 16000 像素 / 边、5000 万像素。备份导入上限 150 MB。实际可保存容量取决于浏览器剩余空间。保存失败会明确提示，并保留当前内存数据以便立即导出备份。

不在多个窗口同时编辑同一套数据；本版带有保存版本冲突检查，发生冲突会暂停本页写入并提示先备份、再刷新恢复副本，避免静默覆盖。它不提供多人实时同步。

## 开发与验证

原生 HTML / CSS / JavaScript，计算规则与界面分离，便于后续接入图纸解析或桌面外壳。

```sh
node --check app.js
node --check server.cjs
node --test tests/core.test.cjs
```

可选浏览器集成测试（需要自行安装 Playwright 及 Chromium，先启动本地服务）：

```sh
node tests/ui.cjs
```

支持环境变量 `PLAYWRIGHT_MODULE` 指定已有 Playwright 包，`MEP_BROWSER_EXECUTABLE` 指定已有 Chromium / Edge 可执行文件，`MEP_TEST_URL` 指定本地测试地址。测试使用独立临时浏览器上下文，不读取日常浏览器数据；截图和验收文件保存在忽略提交的 `test-results/`。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 本地应用入口 |
| `styles.css` | 桌面与手机界面 |
| `app.js` | 图纸交互、项目、备份和收支 |
| `core.js` | 数量计算、材料汇总、CSV 与备份校验 |
| `server.cjs` | 可选本地静态服务 |
| `tests/core.test.cjs` | 计算与数据校验测试 |
| `tests/ui.cjs` | 浏览器完整流程测试 |
| `docs/ROADMAP.md` | 下一步迭代方向 |

## 项目最初目标

服务建筑机电安装工程的日常管理，逐步覆盖水电工程量、工人工资与计件、材料采购入库和使用、电线电缆价格及成本、项目收支、统计报表、CAD 图纸数据处理，并加入可复核的自动算量与 AI 辅助能力。

第一版优先验证：没有算量软件经验的人，能否在提示下完成第一笔可核对的工程量。后续功能依据真实图纸与现场试用反馈推进。
