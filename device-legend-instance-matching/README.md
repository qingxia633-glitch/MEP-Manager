# DeviceLegendInstanceMatchVersion 1

**Contract.** Compare top-level static INSERTs in verified ModelSpace snapshots of one project. A request pins each report, drawing and legend-row artifact by SHA-256. An optional revision-3 targeted probe supplies same-drawing definition members. Input integrity errors reject the run. An instance with no verified definition remains observable.

**Invariant.** In comparison revision `block-local-1`, compare native definition coordinates relative to the block base. Preserve LINE endpoints, ordered LWPOLYLINE vertices, bulges, elevation and widths. CIRCLE uses its OCS center and positive radius. ARC additionally uses ordered counterclockwise endpoints in entget radians. SOLID retains all four raw corners and compares a validated convex boundary in strip order 10, 11, 13, 12. A single repeated adjacent corner may form a nondegenerate triangle. Missing corners, crossed or degenerate boundaries, nonzero thickness, hidden or inclined members remain unresolved. The supported OCS normal is +Z. The supported instance transform is planar rotation, translation and positive uniform scaling. The output retains pose separately from definition geometry. [Autodesk CIRCLE](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-8663262B-222C-414D-B133-4A8506A27C18.htm), [ARC](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-0B14D8F1-0EBA-44BF-9108-57D8CE614BC8.htm), [angle units](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DXF/files/GUID-3F0380A5-1C15-464D-BC66-2C5F094BC8.htm), [SOLID](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DXF/files/GUID-E0C5F04E-D0C5-48F5-AC09-32733E8848F2.htm).

**Failure.** Missing or inconsistent object identity, dynamic/anonymous state, incomplete enumeration, unsupported normals, nested definitions, unsupported graphical entities, mirrors and nonuniform scales preclude equivalence. Several viable rows retain ambiguity. Names and actual/default attribute values retain separate provenance. A partial row can provide a candidate.

**Acceptance.** Supported geometry requires a bounded row and complete qualified native geometry, including widths, filled boundaries and auxiliary POINT positions. Centerline evidence excludes filled regions. POINT positions carry no port assertion. Width differences retain both sides and cap the result at candidate. Raw INSERT presentation differences are recorded separately. The output does not establish effective rendering. Device names reference the legend row, actual ATTRIB and definition defaults separately. Engineering type awaits independent judgment. Geometry gives no authority to propagate model, installation, height, circuit, material or quantity.

**Coverage.** Report integrity is a prerequisite for all definitions. An owner-qualified raw-retained SOLID gap can be scoped only when the validated seed, traversal path and BLOCK_RECORD agree. Every such gap stays in the output. The local definition still requires a verified member walk and fully readable geometry. Other direct definitions can be compared when independent. Unknown gap ownership, unread nodes, nested INSERTs and unresolved direct dependencies block comparison. Shared definitions are checked against their own inventory regardless of which seed enumerated them. A partial acquisition can thus contain independently usable direct geometry. Completion of the report never establishes reverse-association coverage.

The full-report reader accepts the versioned 2.8 ModelSpace top-level export and verifies its independent manifest, source-file identity, completion and read-error count. Supply reviewed artifact pins independently of the files being checked. The probe reader checks the request, raw report, DBMOD trace, Shadow bytes and native BLOCK owner/BLOCK_RECORD using the acquisition verifier. It checks the member walk against the recorded ENTNEXT operations. POINT and invisible ATTDEF records stay in the evidence inventory. Visible text, unsupported member types and unverified termination prevent a complete geometry comparison. Fixed text and instance ATTRIB are never silently substituted for native curve geometry.

The output stores the original member DXF and INSERT transform separately from the ModelSpace insertion point. It compares base-relative curves directly and does not compute a rendering or re-fit a rotated or scaled block definition. Vertex-order differences may require review. Role hints point back to individual texts in the source row. A model or installation instruction located only at row level retains that limitation.

Run `python resolve.py request.json new-result.json`. The request contains `project_id`, source and target drawing inputs (`legend_drawing`, `plan_drawing`), `rows_path` and `rows_sha256`, and `pairs` of [legend INSERT handle, plan INSERT handle]. Each drawing input supplies `report`, `manifest`, `sha256`, `dwg` and `dwg_sha256`. Optional `probe` supplies paths to `report`, `request`, `manifest` and the independently pinned probe `sha256`. Supply every legend under consideration for each instance in the same batch. Results describe those comparisons only.
